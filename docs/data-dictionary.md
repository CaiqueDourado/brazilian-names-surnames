## Conventions

- Encoding UTF-8 without BOM, comma separated, header in the first line. Texts may contain line breaks inside quoted cells.
- Lists inside a cell use `|` as separator.
- Empty cell = unknown or not applicable. Decimal point is `.`.
- `meaning` and `history` were written by language models and never reviewed by a person. Use them as examples of model output, not as facts.
